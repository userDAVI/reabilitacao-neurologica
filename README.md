# Plataforma inteligente de reabilitação neurológica

Este projeto implementa um protótipo demonstrativo web para a proposta de um ecossistema inteligente de reabilitação para pacientes com lesão medular.

## Estrutura
- `index.html` — protótipo funcional do sistema
- `apresentacao.html` — versão de apresentação executiva em slides
- `styles.css` — design system e estilos da plataforma
- `app.js` — interações, dados fictícios e navegação
- `docs/arquitetura.md` — arquitetura conceitual
- `docs/roadmap.md` — roadmap de tecnologias e implementação
- `docs/riscos.md` — matriz de riscos

## Como executar
1. Abra `index.html` diretamente em um navegador, ou
2. Execute um servidor local:

```bash
cd "C:\Users\davii\OneDrive\Documentos\Projeto com Emerson"
python -m http.server 8000
```

Então abra `http://localhost:8000`.

## Observações
- Os dados são fictícios e simulados.
- O objetivo é demonstrar a jornada clínica, multimodal e tecnológica do projeto.
- A solução não substitui validação profissional ou regulatória real.
